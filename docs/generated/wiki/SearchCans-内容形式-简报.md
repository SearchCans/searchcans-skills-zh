# SearchCans 内容形式简报

> 地域化 Google 网页、图片、视频和短视频结果的形式清单

## 最适合的任务

编辑形式发现、视觉/视频搜索研究和 SEO/GEO 内容形式规划。

## 使用的 SearchCans API

- Google 搜索
- Google 图片
- Google 视频
- Google 短视频
- Account

## 账户感知行为

为每个选定形式预检，并按固定优先级限制实际搜索面。

## 调用示例

```text
使用 $searchcans-content-format-brief-zh 映射这个主题在目标市场的内容形式。
```

请阅读可执行的 [SKILL.md](https://github.com/SearchCans/searchcans-skills-zh/tree/main/skills/searchcans-content-format-brief-zh)，了解可用参数、证据边界与报告要求。

## 解释边界

使用 SearchCans 将地域化 Google 网页、图片、视频和短视频结果映射为有界的内容形式简报。适用于 SEO/GEO 内容规划、编辑形式发现、视觉搜索研究，以及决定哪些形式需要进一步页面级验证。
