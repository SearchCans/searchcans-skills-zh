# SearchCans 市场观察

> 包含 Google、Google News、Bing 和 Reader 证据的 URL 级市场快照

## 最适合的任务

竞品、品类、发布、公关与新闻跟踪，并可比较快照。

## 使用的 SearchCans API

- Google 搜索
- Google News
- Bing 搜索
- Reader
- Account

## 账户感知行为

一次预检，限制新闻来源读取，并遵循报告的 Lane 数。

## 调用示例

```text
使用 $searchcans-market-watch-zh 为这个品类创建美国市场快照。
```

请阅读可执行的 [SKILL.md](https://github.com/SearchCans/searchcans-skills-zh/tree/main/skills/searchcans-market-watch-zh)，了解可用参数、证据边界与报告要求。

## 解释边界

使用 SearchCans Google 搜索、Google News、Bing 搜索和选定 Reader 提取创建有界、地域化、可追溯的市场观察快照。适用于竞品与品类监测、公关和新闻追踪、发布情报，以及两个有限运行之间的 URL 级变化检查。
