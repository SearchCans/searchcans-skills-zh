# SearchCans 商品 SERP 简报

> 包含 Google Shopping、网页、图片和可选商家页面证据的简报

## 最适合的任务

电商品类研究、商家发现、商品页规划和地域化陈列策略。

## 使用的 SearchCans API

- Google Shopping
- Google 搜索
- Google 图片
- Reader
- Account

## 账户感知行为

预估三次 SERP 与明确 Reader URL；需要时仅限制来源读取。

## 调用示例

```text
使用 $searchcans-product-serp-brief-zh 调研这个商品品类在美国市场的搜索表现。
```

请阅读可执行的 [SKILL.md](https://github.com/SearchCans/searchcans-skills-zh/tree/main/skills/searchcans-product-serp-brief-zh)，了解可用参数、证据边界与报告要求。

## 解释边界

使用 SearchCans Google Shopping、Google 网页、Google 图片和明确指定的 Reader 商家 URL 创建地域化商品搜索证据简报。适用于电商品类研究、竞品商品组合发现、商品页规划和市场特定的陈列策略简报。
