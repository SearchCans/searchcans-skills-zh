# 选择 Skills

选择能产生所需证据或产物的最小 Skill。仅当上一个产物成为下一个 Skill 的有界输入时，再组合使用。

| 目标 | Skill | 原因 |
| --- | --- | --- |
| 市场、竞品、技术、政策、公司和产品的当前网页研究 | [SearchCans 中文深度研究](SearchCans-中文深度研究) | 包含可追溯 URL、冲突与不确定性的有界研究简报 |
| 关键词研究、搜索意图分析、竞品页面审查和内容机会规划 | [SearchCans SERP 内容差距](SearchCans-SERP-内容差距) | 基于已观察 Google 或 Bing SERP 特征的地域化内容机会简报 |
| 网页转 Markdown、RAG 输入检查、动态页、PDF、Office 文件和页面级 SEO/GEO 审查 | [SearchCans Reader SEO 审计](SearchCans-Reader-SEO-审计) | 包含 canonical、H1、meta description、JSON-LD、文件和截图信号的提取报告 |
| 竞品、品类、发布、公关与新闻跟踪，并可比较快照 | [SearchCans 市场观察](SearchCans-市场观察) | 包含 Google、Google News、Bing 和 Reader 证据的 URL 级市场快照 |
| 电商品类研究、商家发现、商品页规划和地域化陈列策略 | [SearchCans 商品 SERP 简报](SearchCans-商品-SERP-简报) | 包含 Google Shopping、网页、图片和可选商家页面证据的简报 |
| 编辑形式发现、视觉/视频搜索研究和 SEO/GEO 内容形式规划 | [SearchCans 内容形式简报](SearchCans-内容形式-简报) | 地域化 Google 网页、图片、视频和短视频结果的形式清单 |
| Grounding Pack、来源策展、知识库入库和预入库证据检查 | [SearchCans RAG 来源策展](SearchCans-RAG-来源策展) | 小规模、域名多样且经过 Reader/文件提取验证的来源清单 |

## 选择规则

- 需要多来源、3–5 个子问题和正式证据门槛时，用 **中文深度研究**。
- 一个地域化关键词/SERP 决策用 **SERP 内容差距**；决策涉及图片、视频和短视频形式时，用 **内容形式简报**。
- 已知单个 URL 或文件用 **Reader SEO 审计**；先发现并选择少量来源，再入库时用 **RAG 来源策展**。
- 可重复的市场/新闻快照用 **市场观察**；特定市场的商品与商家观察用 **商品 SERP 简报**。

SERP 摘要和结果展示不是证据。重要主张前必须读取相应页面。
