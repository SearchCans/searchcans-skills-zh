# SearchCans 中文深度研究

> 包含可追溯 URL、冲突与不确定性的有界研究简报

## 最适合的任务

市场、竞品、技术、政策、公司和产品的当前网页研究。

## 使用的 SearchCans API

- Google 或 Bing 搜索
- Reader
- Account

## 账户感知行为

一次预检，限制 Reader 来源数，并让并发不超过报告的 Parallel Lane。

## 调用示例

```text
使用 $searchcans-deep-research-zh 调研美国 SERP API 市场的最新变化。
```

请阅读可执行的 [SKILL.md](https://github.com/SearchCans/searchcans-skills-zh/tree/main/skills/searchcans-deep-research-zh)，了解可用参数、证据边界与报告要求。

## 解释边界

使用 SearchCans SERP API 和 Reader API 执行有界、证据驱动、账户感知的中文深度研究。适用于需要当前网页证据的市场、竞品、技术、政策、公司或产品问题；先规划 3–5 个子问题，指定市场和语言，读取来源、处理冲突，并交付可追溯 URL 的研究简报。
